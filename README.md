A one-star review of Monday written as though Monday were a restaurant, 25 words or fewer — written by a small deterministic Node 22 program: [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61).

> One star. Seated at 9am, served cold coffee at noon, and billed for a weekend I never ordered. Monday, never again.

## Run it

```sh
node main.ts
```

It writes the review to `/output/entry.txt` (UTF-8, 115 characters, one line, 21 words).
